ClipperBot Privacy Policy

Last updated: October 17, 2026

Summary

ClipperBot runs entirely on its owner's own computer. It has no servers, no user accounts, no analytics and no advertising. It does not sell, share or send personal data to anyone, except clips the user chooses to send to their own TikTok account.

Data from TikTok

When the user connects their TikTok account, ClipperBot receives from TikTok:

  • an access token and refresh token, used only to upload clips to that same account as drafts;
  • basic profile info (display name, avatar, open ID), used only to show which account is connected.

This data is stored only in a local file on the user's computer. It is never sent anywhere except back to TikTok's official API. Disconnecting in ClipperBot deletes it. The user can also revoke access in their TikTok app settings.

Videos and clips

Videos, recordings, transcripts and clips are processed and stored only on the user's computer. A clip leaves the computer only when it is uploaded to the user's own TikTok account as a draft, either because the user clicked "Send to TikTok" or because they turned on auto-send.

Third parties

ClipperBot downloads public videos and streams the user asks for from Twitch, Kick or YouTube, and talks to TikTok's API as described above. Their own privacy policies apply to those services.

Children

ClipperBot is not directed to children and does not knowingly process children's data.

Changes

This policy may be updated. The date at the top shows the latest version.
